Dual-Layer Validation Architecture: Pydantic vs. Evaluator LLM

How structural guardrails and semantic quality evaluation complement each other in Hermes.

Layer 1: Structural & Syntactic (Pydantic)

Checks field types, min/max bounds, required keys, JSON format, and string schemas. Runs deterministically with zero token costs and microsecond latency.

Failure caught: Missing key 'summary', temperature string passed instead of float.
Layer 2: Semantic & Quality (Judge LLM)

Checks goal completeness, factual accuracy, absence of hallucinations, and compliance with user instructions. Operates on clean context window with rubric scoring.

Failure caught: JSON schema is valid, but draft forgot to answer second half of prompt.

Pydantic v2 Guardrails at Every Data Boundary

Explore how Hermes uses strict schema models to eliminate malformed JSON, invalid arguments, and context pollution.

GUARDRAIL 1 Entrypoint

User Request Sanitization

Validates user prompt inputs before LLM tokenization. Enforces maximum character lengths, validates client session IDs, and strips harmful injections.

class UserRequestSchema(BaseModel):
  query: str = Field(min_length=3, max_length=2000)
  user_id: UUID4
  permissions: List[str]
GUARDRAIL 2 LangGraph State

State Contract (`HermesState`)

LangGraph nodes mutate a central state dictionary. Pydantic ensures nodes never pollute memory with invalid types or broken history sequences.

class HermesState(BaseModel):
  messages: List[ChatMessage]
  tool_calls: List[ToolCallRequest] = []
  retry_count: int = 0
GUARDRAIL 3 Tool Execution

Tool Argument Validation

When LLMs output JSON to trigger tools (e.g., SQL queries, API calls), Pydantic parses arguments. If invalid, catches `ValidationError` and feeds error string back to LLM for auto-retry.

class DatabaseQueryArgs(BaseModel):
  table_name: Literal["users", "orders"]
  limit: int = Field(default=10, le=100)
GUARDRAIL 4 Tool Return

Tool Result Sanitization

Third-party APIs can return bloated payloads, HTML, or credentials. Pydantic cleans and structures raw output before appending it back into LLM memory.

class ToolResultPayload(BaseModel):
  status_code: int
  data: Dict[str, Any]
  sanitized_summary: str

Hermes Harness Production Code Blueprint

Complete reference implementation combining LangGraph state graph with Pydantic v2 schemas and Evaluator Judge node.

# hermes_agent_harness.py - LangGraph + Pydantic + Evaluator Judge Pattern
from typing import List, Dict, Any, Literal, Optional
from pydantic import BaseModel, Field, ValidationError
from langgraph.graph import StateGraph, END

# ==========================================
# 1. PYDANTIC SCHEMAS (STRUCTURAL & JUDGE)
# ==========================================

class UserRequest(BaseModel):
    query: str = Field(..., min_length=2, max_length=1000)

class EvaluationResult(BaseModel):
    """Pydantic schema for the Evaluator Node (Judge LLM)."""
    is_satisfactory: bool = Field(description="True if candidate answer completely fulfills user goal.")
    score: float = Field(ge=0.0, le=1.0)
    critique_feedback: Optional[str] = Field(default=None, description="Actionable feedback if unsatisfactory.")

class HermesState(BaseModel):
    """LangGraph central state model enforced by Pydantic."""
    query: str
    messages: List[Dict[str, Any]] = []
    pending_tool_call: Optional[Dict[str, Any]] = None
    tool_results: List[Dict[str, Any]] = []
    draft_response: Optional[str] = None
    eval_result: Optional[EvaluationResult] = None
    retry_count: int = 0
    max_retries: int = 3

# ==========================================
# 2. LANGGRAPH NODES & EVALUATOR NODE
# ==========================================

def agent_reasoner_node(state: HermesState) -> Dict[str, Any]:
    # Worker LLM plans tool call or generates response
    pass

def evaluator_node(state: HermesState) -> Dict[str, Any]:
    """Dedicated Judge LLM evaluating draft response against original goal."""
    prompt = f"GOAL: {state.query}\nDRAFT: {state.draft_response}"
    
    # Call secondary LLM forcing EvaluationResult output schema
    result: EvaluationResult = judge_llm.with_structured_output(EvaluationResult).invoke(prompt)
    
    if not result.is_satisfactory:
        # Inject critique feedback back into context for re-try
        critique_msg = {"role": "user", "content": f"CRITIQUE: {result.critique_feedback}"}
        return {
            "eval_result": result,
            "retry_count": state.retry_count + 1,
            "messages": state.messages + [critique_msg]
        }
    return {"eval_result": result}

def judge_decision_router(state: HermesState) -> str:
    if state.eval_result and state.eval_result.is_satisfactory:
        return "end"
    if state.retry_count >= state.max_retries:
        return "end"  # Exit to avoid infinite loop
    return "retry_reasoner"

# ==========================================
# 3. BUILD GRAPH
# ==========================================

workflow = StateGraph(HermesState)
workflow.add_node("reasoner", agent_reasoner_node)
workflow.add_node("evaluator", evaluator_node)

workflow.add_conditional_edges(
    "evaluator",
    judge_decision_router,
    {"end": END, "retry_reasoner": "reasoner"}
)
